## 1. 동생(나영) 기일 0902 → 0903

**배경:** 엄마는 "내일이 기일"이라고 하는데, 회귀 날짜가 0902라서 기일(0902)과 하루가 어긋났다.

**결정:** 기일을 0903으로 옮긴다. 금고 비밀번호와 박주원 일기 날짜도 함께 0903으로 바꾼다. 회귀 날짜 0902와 사망 시각 0903 오전 7시는 그대로 둔다.

**변경**
- `chat.js`: 금고 정답 체크, 추천 질문 ("동생 기일이 9월 3일이에요?", "0903이 무슨 날이에요?")
- `triggers.json`: password 트리거의 키워드, 메시지, 단서 카드
- `기본단서1_녹음테이프.md`, `AB단서3_택배상자_속_일기장_route101.md`
- `세계관.md`: "동생(나영) 기일 : 0903" 항목 추가
- 벡터스토어 재빌드: `cd llm && python -m vector_store.build_store --reset`

> 오프닝의 "9월 3일"을 현재 날짜로 바꾸는 안은 검토 후 보류했다. 0902/0903이 비밀번호, 기일, 일기에 엮인 퍼즐 구조라서 바꾸면 연결이 깨진다.

## 2. 오프닝 개편 (나레이션 = 시스템, 치키 = 관리자)

**컨셉:** 나레이션은 게임 시스템 그 자체이고, 치키는 그 시스템을 운영하는 관리자(실제로는 집행자)다.

- 치키 대사 → 2인칭 존댓말 나레이션 14줄. 이름표는 `SYSTEM`
- 나레이션이 끝나면 치키(`치키 · ADMIN`)가 등장해 마지막 대사를 한다
- "기회는 총 3번" 추가 (나레이션 + 규칙 카드)
- 치키 대사: "남의 마음은 그렇게 잘 들여다보면서… / 정작 **네 마음속**은 한 번도 안 들여다봤지?" (반전 복선)
- 카드
  - PROFILE: 직업 "정신건강의학과 <안식> 상담사", 나이 34세 (차서연과 동갑)
  - SUSPECTS: 김도현 "<안식>의 내담자", 차서연 "<안식>의 정신건강의학과 의사", 박도원 "<안식>의 청소부", 윤미경 "당신의 어머니"

## 3. 성별 호칭 버그 수정

**문제:** 프론트는 성별을 "남성"/"여성"으로 보내는데, `base.py`의 `get_child_term()`과 `get_sibling_term()`은 "남자"인지만 확인했다. 그래서 남성 플레이어도 엄마에게 "우리 딸", 동생에게 "언니"로 불렸다.

**수정:** "남"으로 시작하면 남성으로 판단한다 (남 / 남자 / 남성 모두 처리).

## 6. 엔딩 개편

**목표:** 배드엔딩의 소름과 무력감. 참고한 작품은 〈블랙 미러〉 '화이트 베어', 〈트라이앵글〉, 〈퍼니 게임〉, 〈셔터 아일랜드〉 등이다.

**흐름**
1. SYSTEM — 판정: 생존 실패, 남은 기회 0 / 3, 침입·사망 시각, "대상은 단 한 번도 자신을 의심하지 않았습니다."
2. 치키 — "……아아. 결국 또 여기까지 왔네 🐰"
3. SYSTEM — 사건 기록 조회 (나영, 김하윤, 박주원). 피해자 규모는 계속 깨지는 글자로 숨긴다
4. 형벌 집행 통지서 — 공문서 디자인, 비고에 "집행자 — 치키" 도장
5. 치키 — 남겨진 네 사람(너희 엄마, 김도현, 박도원, 차서연)이 일상을 되찾는 모습 (이모지 없이)
6. SYSTEM — 기억 삭제
7. SYSTEM — 9월 2일 오전 7시. LOOP 1 / 버튼 '눈을 뜬다'

**주요 결정**
- 가해자는 이름이 아니라 **수감번호 `0903-4127`**로만 부른다
- 시스템은 모든 걸 아는 존재다. 그래서 "확인된", "조사 중" 같은 표현은 쓰지 않고, 피해자 규모는 '알지만 보여주지 않는' 연출로 처리한다
- 첫 판정은 "범인 지목 실패"가 아니라 "생존 실패"로 한다. 시간 초과나 채팅 중 사망으로도 엔딩에 올 수 있기 때문이다
